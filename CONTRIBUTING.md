# Contributing

Thanks for wanting to help! IMMORTAL-S3 is **closed-source**, so firmware
pull requests are not accepted.

## What I want

- Bug reports
- Feature requests
- Screenshots
- Documentation fixes
- Translations

## What I can't accept

- Pull requests touching proprietary firmware source
- Redistributed firmware builds
- Requests to open-source the project

## Reporting bugs

Include:

1. Board and ESP32-S3 variant
2. Firmware version
3. Exact steps
4. Observed behavior
5. Expected behavior
6. Serial logs at 115200 baud

Thanks for understanding the closed-source stance.
