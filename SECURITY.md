# Security policy

## Reporting a vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities.

Email **<your-contact-email>** with:

- A short description
- Steps to reproduce
- Proof-of-concept if appropriate
- Your name / handle if you want credit

Confirmed issues are patched in a future release where possible.

## Scope

In scope:
- Compiled firmware
- Device web dashboard
- Web flasher in `docs/`

Out of scope:
- Third-party library vulnerabilities
- Physical attacks requiring hardware access
- Social engineering
