IMMORTAL-S3

A pocket-sized wireless research platform. WiFi · BLE · Sub-GHz · IR · BadUSB · AI · OLED.

● Web Flasher ESP32-S3 Chrome / Edge ~30 seconds

Install IMMORTAL-S3

Plug your board into a USB data port, then click below.

Your browser doesn't support WebSerial. Use Chrome, Edge, or Opera on desktop. WebSerial requires HTTPS.
Requires a USB data cable · Hold BOOT while plugging in if needed

How to flash

Three steps. No IDE, no Python, no drivers on most systems.

Plug in the board

Use a USB data cable. If nothing appears, enter download mode with BOOT/IO0.

Click INSTALL

Pick the serial port and let the flasher write and verify the image.

Open the local dashboard

After boot, connect to the device's local network and open its dashboard.
