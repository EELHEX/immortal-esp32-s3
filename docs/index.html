How to flash

Three steps. No IDE, no Python, no drivers on most systems.

Plug in the board

Use a USB data cable. If nothing appears, enter download mode with BOOT/IO0.

Click INSTALL

Pick the serial port and let the flasher write and verify the image.

Open the dashboard

After boot, join the AP immortal / admin1234 and open 192.168.4.1.

NRF24 Radios

Two IMMORTAL-S3 boards can talk to each other without any WiFi infrastructure — voice and text.

Walkie Talkie

Push-to-talk voice over NRF24

µ-law 8 kHz codec, 20 ms frames, 2 Mbps link on channel 90. Live link-quality estimate and distance readout on the OLED.

  • HTTPS on port :8443 (Safari / iOS mic access)
  • HTTP on port :81 (Chrome desktop fallback)
  • Self-signed EC P-256 certificate (auto-generated)
  • Drop counters + quality bar on device

https://192.168.4.1:8443/walkie
http://192.168.4.1:81/walkie

Ghost Chat

Text messaging without WiFi

Two boards exchange encrypted-free messages over the NRF24 link. Roles A / B, reply-to, reactions, delivered ticks, typing indicator.

  • 28-character messages (single 32-byte packet)
  • Reactions: +1 · +haha · +heart · +!
  • Unread badge on the OLED main menu
  • Per-device chat log in LittleFS
